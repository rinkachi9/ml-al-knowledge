# What is AI

Definitions of artificial intelligence, the nesting of AI, machine learning, deep learning and generative AI, and the vocabulary of models.

This section is part of the knowledge area [AI foundations](../README.md). Read the notes in the order below.

## Notes

- [Artificial intelligence](artificial-intelligence.md): Artificial intelligence (AI) is the field that builds computer systems which perform tasks that would need intelligence if a person did them: perceiving, reasoning, planning, learning, using language and acting toward goals.
- [AI model](ai-model.md): An AI model is a parameterized function that maps inputs to outputs, together with the learned values of its parameters.
