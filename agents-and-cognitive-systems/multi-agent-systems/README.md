# Multi-agent systems

Several agents that collaborate, compete or are organized in hierarchies.

This section is part of the knowledge area [Agents and cognitive systems](../README.md). Read the notes in the order below.

## Notes

- [Multi-agent systems](multi-agent-systems.md): A multi-agent system consists of several agents that interact to reach goals: they collaborate on shared goals, compete or evaluate each other, or are organized in a hierarchy where a manager agent delegates to workers.
