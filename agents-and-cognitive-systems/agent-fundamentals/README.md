# Agent fundamentals

What an agent is, how its task environment is described, and the main types of agents.

This section is part of the knowledge area [Agents and cognitive systems](../README.md). Read the notes in the order below.

## Notes

- [AI agent](ai-agent.md): An AI agent is a system that perceives its environment, reasons about its goals and context, decides on actions and carries them out through tools or interfaces, often in a loop until the goal is reached.
- [Agent types](agent-types.md): Agents are classified by how they choose actions.
