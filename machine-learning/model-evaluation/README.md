# Model evaluation

Estimating how a model will perform on new data, and the metrics that measure it.

This section is part of the knowledge area [Machine learning](../README.md). Read the notes in the order below.

## Notes

- [Training, validation and test data](training-validation-and-test-data.md): A model is fitted on *training data*, tuned on *validation data* and judged once on *test data* that played no part in building it.
- [Classification metrics](classification-metrics.md): Classification metrics summarize how often and in which way a classifier is wrong.
- [Regression metrics](regression-metrics.md): Regression metrics measure how far numeric predictions are from the actual values.
