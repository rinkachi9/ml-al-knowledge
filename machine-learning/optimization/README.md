# Optimization

Training as optimization: loss functions and the gradient based methods that minimize them.

This section is part of the knowledge area [Machine learning](../README.md). Read the notes in the order below.

## Notes

- [Loss functions](loss-functions.md): A loss function (also called a cost function or objective) measures how far a model's prediction `ŷ` is from the actual value `y`.
- [Gradient descent](gradient-descent.md): Gradient descent is the iterative method that adjusts a model's parameters in the direction that reduces the loss.
