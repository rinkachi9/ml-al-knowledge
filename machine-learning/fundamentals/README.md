# Machine learning fundamentals

What machine learning is, its vocabulary, and the central problem of generalization.

This section is part of the knowledge area [Machine learning](../README.md). Read the notes in the order below.

## Notes

- [Machine learning](machine-learning.md): Machine learning (ML) is the branch of artificial intelligence in which computers learn to make decisions or predictions from data instead of being explicitly programmed with rules.
- [Features and labels](features-and-labels.md): A *feature* is a measurable input property that a model uses to make a prediction, such as age, income or location.
- [Overfitting and underfitting](overfitting-and-underfitting.md): *Overfitting* happens when a model learns too much from its training data, including the noise, and performs poorly on new data.
