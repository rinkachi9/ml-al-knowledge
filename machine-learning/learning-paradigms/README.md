# Learning paradigms

Supervised, unsupervised and reinforcement learning, distinguished by the feedback the learner receives.

This section is part of the knowledge area [Machine learning](../README.md). Read the notes in the order below.

## Notes

- [Supervised learning](supervised-learning.md): In supervised learning the algorithm learns from labeled data: every training input comes with its correct output, and the goal is to learn a mapping from inputs to outputs that is also correct for new inputs.
- [Unsupervised learning](unsupervised-learning.md): In unsupervised learning the algorithm learns patterns from unlabeled data: it finds hidden structure, such as groups, directions of variation or unusual points, without a predefined correct answer.
- [Reinforcement learning](reinforcement-learning.md): In reinforcement learning (RL) an agent learns by interacting with an environment: it takes actions, receives feedback in the form of rewards or penalties, and adjusts its behavior to maximize the total reward over time.
