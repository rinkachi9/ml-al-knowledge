# Hardware accelerators

GPUs, TPUs and the programming models that drive them.

This section is part of the knowledge area [ML systems](../README.md). Read the notes in the order below.

## Notes

- [CUDA](cuda.md): CUDA (Compute Unified Device Architecture) is NVIDIA's parallel computing platform and programming model for its GPUs.
- [Tensor Processing Unit (TPU)](tpu.md): A Tensor Processing Unit (TPU) is an application-specific integrated circuit (ASIC) that Google designed to accelerate neural network computations.
